# Дизайн-документ — Type Faster

## 1. Общее описание

**Type Faster** — десктопная игра на C# (Windows Forms, .NET 9.0), в которой игрок набирает слова с клавиатуры на скорость. Цель — набрать максимум опыта (XP) за 30-секундный раунд.

Паттерн проектирования: **MVP** (Model-View-Presenter).

---

## 2. Геймплей

### Основной цикл

1. Игрок нажимает «Начать игру».
2. На экране отображается слово с выделенной текущей буквой в квадратных скобках: `пр[о]грамма`.
3. Если игрок вводит **правильную букву** — начисляется опыт, индекс буквы сдвигается.
4. Если буква **неверная** — опыт снимается, комбо сбрасывается, буква остаётся той же.
5. Когда слово набрано полностью:
   - Опыт, накопленный за буквы этого слова, умножается на **коэффициент редкости слова**.
   - Если время раунда не вышло — выдаётся следующее слово.
6. Раунд длится **30 секунд** (таймер тикает каждую секунду).
7. По истечении времени показывается экран завершения с итоговым опытом и рекордом.

### Комбо

Счётчик комбо увеличивается на **каждую правильную букву** и сбрасывается на **любой ошибке**.

| Диапазон комбо | Множитель опыта |
|---|---|
| 0–9 | ×1.0 |
| 10–19 | ×1.1 |
| 20–49 | ×1.2 |
| 50+ | ×1.3 |

При достижении порогов 10, 20 и 50 на экране отображается подсказка (КОМБО x10!, x20!!, x50!!!).

### Визуальная обратная связь

- Фон поля ввода становится **зелёным** при правильной букве, **красным** при ошибке.
- Используется шрифт **Pangolin** (с запасным Segoe UI).

## 3. Система опыта (XP)

### Опыт за букву

Базовая формула при правильной букве:

```
gain = round(5 × (1 + rarity + eventBonus) × comboMultiplier)
```

Где:
- `5` — базовый опыт за букву.
- `rarity` — коэффициент редкости буквы (0.1 — 1.0).
- `eventBonus` — +0.1, если активно событие (режим городов).
- `comboMultiplier` — множитель комбо (1.0 / 1.1 / 1.2 / 1.3).

### Штраф за ошибку

```
penalty = round(2 × (1 - rarity))
totalXP = max(0, totalXP - penalty)
```

### Бонус за слово

При полном наборе слова:

```
bonus = round(currentWordBaseXP × wordRarity)
```

Если активно событие — `bonus *= 2`.

Где `currentWordBaseXP` — сумма всего опыта, полученного за буквы этого слова (с учётом комбо и событий до момента бонуса).

### Коэффициенты редкости букв

| Буквы | Коэффициент |
|---|---|
| е, о | 0.1 |
| а | 0.15 |
| и, н, т | 0.2 |
| с | 0.25 |
| р, в, л | 0.3 |
| к, м | 0.4 |
| д, п, у | 0.5 |
| я | 0.6 |
| ы, з | 0.7 |
| ь, б, г | 0.8 |
| ч, й, х | 0.9 |
| ж, ш, ц, щ, ф, э, ю, ъ | 1.0 |

### Коэффициенты редкости слов

Хранятся как явный словарь (пример: `"мама" → 0.1`, `"шифрование" → 1.0`). Для слов, отсутствующих в словаре, применяется значение по умолчанию **0.5**.

## 4. Словарь

### Формат

Словарь — текстовый файл `.txt` в папке `{StartupPath}/Dictionaries/`, одно слово на строку.

### Утилита WordParser

Статический класс `WordParser.Parse(string rawText)`:
1. Нормализует переводы строк и табуляции в пробелы.
2. Разбивает по пробелам.
3. Очищает каждое слово регулярным выражением `[^\p{L}\p{N}-]` (оставляются буквы, цифры и дефисы).

### Поставляемые словари

- **Стандартный.txt** — 5 слов (по умолчанию: фрукты).
- **Сыграем в города.txt** — 30 названий городов мира (для ивента).

### Управление словарями

Через форму **DictionaryForm** игрок может:
- Создать новый словарь (название + список слов).
- Загрузить слова из `.txt` файла.
- Сохранить словарь в папку `Dictionaries/`.
- Выбрать активный словарь для игры.

### Интерфейс IDictionaryRepository

```csharp
public interface IDictionaryRepository
{
    IEnumerable<string> GetDictionaryNames();
    List<string> LoadDictionary(string name);
    void SaveDictionary(string name, List<string> words);
    bool DictionaryExists(string name);
}
```

Реализация — `FileDictionaryRepository` (файловая система).

## 5. Система событий

### Архитектура

Базовый класс `GameEvent` определяет жизненный цикл события:

| Метод | Назначение |
|---|---|
| `CanTrigger(model)` | Проверка условия активации |
| `Trigger(model)` | Активация события |
| `OnPlayerMistake(model)` | Обработка ошибки игрока |
| `OnEventWordCompleted(model)` | Завершение слова в контексте события |
| `OnTick(model)` | Каждый тик таймера (1 сек) |
| `End(model)` | Завершение и сброс |

Менеджер `EventManager` управляет списком событий и активным событием. Одновременно может быть активно только одно событие.

### Событие «Сыграем в города?» (CityEvent)

**Условие активации** (проверяется после каждого завершённого слова):
- Событие ещё не активно.
- Словарь городов загружен.
- Случайный шанс 1/6 (~16.7%).

**Ход события:**

1. Игроку показывается слово **«город»**.
2. Если игрок ошибается — событие завершается, восстанавливается обычный словарь.
3. Если слово введено без ошибок:
   - Игрок получает **+7 секунд** к таймеру.
   - Включается **режим городов** на 7 тиков (7 секунд реального времени).
   - Слова заменяются на названия городов.
   - Активен `eventBonus = +0.1` к каждой букве, бонус за слово удваивается.
4. После отсчёта 7 секунд словарь восстанавливается.

## 6. Архитектура MVP

```
MainMenuForm
    │
    ├── Создаёт GameModel (Model)
    ├── Создаёт MainForm (View, реализует IGameView)
    ├── Создаёт GamePresenter(view, model)
    └── Показывает MainForm как модальное окно
```

### Поток данных

```
[View] MainForm (IGameView)
    │  OnStartClicked ──────► GameModel.StartGame()
    │  OnKeyPressed  ──────► GameModel.ProcessInput()
    │
    │  ◄── OnXPChanged      ── UpdateXP()
    │  ◄── OnWordChanged    ── UpdateWord()
    │  ◄── OnTimerChanged   ── UpdateTimer()
    │  ◄── OnComboChanged   ── UpdateCombo()
    │  ◄── OnEventMessage   ── UpdateEventMessage()
    │  ◄── OnGameEnded      ── ShowEndScreen()
    │
[Presenter] GamePresenter
    (только связывает Model и View, логики не содержит)

[Model] GameModel
    ├── EventManager ── CityEvent
    ├── WordParser
    ├── DictionaryRepository
    └── ScoreRepository
```

### IGameView (интерфейс представления)

```csharp
public interface IGameView
{
    void UpdateWord(string displayWord);
    void UpdateXP(int xp);
    void UpdateTimer(TimeSpan timeLeft);
    void UpdateCombo(string comboText);
    void UpdateEventMessage(string message);
    void ShowEndScreen(int finalXP);

    event Action OnStartClicked;
    event Action<char> OnKeyPressed;
}
```

## 8. Формы (View)

### MainMenuForm
- Точка входа после `Program.Main()`.
- Кнопки: «Начать игру», «Настройки».
- Загружает последний использованный словарь из `last_dictionary.txt`.
- Создаёт MVP-триаду и запускает `MainForm`.

### MainForm (IGameView)
- Основной игровой экран.
- Отображает: слово (крупно), XP, таймер, комбо, сообщения событий, рекорд.
- Скрытый TextBox для захвата клавиатурного ввода.
- Визуальная индикация правильной/неправильной буквы.

### SettingsForm
- Кнопки: «Управление словарями» → DictionaryForm, «Сбросить данные игрока».
- Возвращает выбранный словарь в MainMenuForm.

### DictionaryForm
- Создание, загрузка, сохранение и выбор словарей.
- ComboBox со списком доступных словарей.

### GameOverForm
- Показывает итоговый XP, рекорд, NEW RECORD.
- Простая кнопка OK для закрытия.

## 9. Сохранение данных

| Файл | Назначение |
|---|---|
| `{StartupPath}/Dictionaries/best_score.txt` | Лучший счёт (целое число) |
| `{StartupPath}/Dictionaries/*.txt` | Пользовательские словари |
| `{StartupPath}/last_dictionary.txt` | Имя последнего выбранного словаря |

- `ScoreRepository` — чтение и запись рекорда.
- `FileDictionaryRepository` — управление словарями (CRUD).
