Type Faster
Игра на скорость набора текста на C# (Windows Forms, .NET 9.0). Паттерн — MVP.

Набирайте слова с клавиатуры, получайте опыт, собирайте комбо и ставьте рекорды за 30 секунд!

Геймплей
Вам показывается слово с выделенной текущей буквой: пр[о]грамма
Правильная буква → +опыт, следующая буква
Ошибка → −опыт, сброс комбо, остаётесь на той же букве
Слово полностью → опыт за буквы умножается на редкость слова
Раунд: 30 секунд, цель — максимум XP
Комбо
Комбо	Множитель
0–9	×1.0
10–19	×1.1
20–49	×1.2
50+	×1.3
Случайное событие «Сыграем в города?»
Шанс ~1/6 после завершения слова. Введите «город» без ошибок → +7 секунд, режим городов с повышенным опытом на 7 секунд.

Управление словарями
Создавайте и загружайте собственные словари через меню «Настройки» → «Управление словарями». Словари хранятся в папке Dictionaries/ как текстовые файлы (одно слово на строку).

Установка
Скачайте последний релиз.
Запустите Type faster.exe.
Требуется .NET 9.0 SDK.
